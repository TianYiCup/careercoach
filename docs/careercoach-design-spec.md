## 1. 设计哲学

### 1.1 一句话定调

> **如果即刻、Soul、Duolingo 生了个孩子去当教练——它会是 CareerCoach 的样子。**

不是中规中矩的 SaaS，是**敢吐槽、有梗、能截图发 po、用起来上头**的 AI 教练。

### 1.2 用户原话（Z 世代心声）

我们的目标用户**不会**对一款产品说：

- ❌ "这款 AI 助手很专业"
- ❌ "界面简洁大气"
- ❌ "效率提升了 30%"

他们会说：

- ✅ "**这破玩意儿太上头了**"
- ✅ "**我把战报发我妈了**"
- ✅ "**这教练真敢说**"
- ✅ "**笑死，怎么连他都被我吐槽**"

如果设计稿不能让团队脑补出这种话——重画。

### 1.3 五条核心原则

| # | 原则 | 一句话 | 反例 |
|---|------|--------|------|
| 1 | **有人格** | 不是工具，是个角色 | 冷冰冰的"AI 助手为您服务" |
| 2 | **有态度** | 敢说话敢玩梗 | 万年模板"请稍候..." |
| 3 | **可分享** | 关键瞬间生成可发朋友圈的卡 | 截图里全是 UI 组件 |
| 4 | **多巴胺** | 颜色、动效、震动给即时反馈 | 灰扑扑、按了没反应 |
| 5 | **真克制** | 鲜艳但不混乱，有梗但不油腻 | 五彩弹幕 + 闪烁 GIF |

### 1.4 情感锚点

| 瞬间 | 我们要让用户感到 | 视觉手段 |
|------|------------------|---------|
| 第一次开对练 | "草，居然真的像在跟人聊天" | 全屏渐变进场 + 教练 K 出场动画 |
| 教练给反击话术 | "卧槽好爽" | 卡片弹簧入场 + 紫色发光 + 震动反馈 |
| 看到高光时刻 | "我可以的" | 金色贴纸 + 微闪光 + 烟花粒子 |
| 被点出失分点 | "确实有点菜" 但不是"我好废" | 教练 K 翻白眼表情 + 段子式文案 |
| 解锁弱点画像 | "草，AI 比我自己还懂我" | Wrapped 风可分享大卡 |

## 3. Mascot · 教练 K

### 3.1 角色设定

```
名字：教练 K（K-Coach / Coach K）
物种：紫色 Mochi 软糯生物（球形 + 拳套）
性格：嘴硬心软、爱吐槽、敢说真话、偶尔摆烂
背景：曾在 500 强当过 HR、做过销售、被甲方虐过——所以懂你
口头禅：
  · "兄弟，这话不能这么说啊"
  · "稳住，咱不能怂"
  · "卧槽你这波操作我都没想到"
  · "翻车了翻车了，但还能救"
```

### 3.2 视觉描述

```
   ╭─────╮
  ╱  •̀ω•́  ╲     ← 大眼睛 + 表情多变
 │    Δ     │    ← 鼻子小三角
 ╰─┰─────┰─╯
   ┃ KK  ┃     ← 拳套（左红右紫）
   ╰─────╯
```

- **基础形态**：紫色（`--vivid-purple`）软糯球，类似 Duolingo Duo 但圆润
- **配饰**：永远戴着一对拳击手套（左红 `#FF6B35` / 右紫 `#6C4DFF`）
- **比例**：头身比 1.5:1（萌系）
- **轮廓**：1.5pt 黑色描边（贴纸感）

### 3.3 八种表情（核心情感锚点）

| 表情 | 触发场景 | 描述 |
|------|---------|------|
| 😎 自信 | 进入对练房 | 戴墨镜、嘴角上扬 |
| 🔥 热血 | 对练中给反击话术 | 头顶火焰、瞪眼 |
| 🤔 思考 | 教练正在生成提示 | 一只手套托腮 |
| ✨ 封神 | 高光时刻 | 闭眼微笑、头顶光环 |
| 😅 翻车 | 失分点 | 翻白眼、汗滴 |
| 🤡 整活 | 幽默档提示 | 戴小丑帽、wink |
| 🥹 心疼 | 用户连续翻车 | 抱着用户头像安慰 |
| 💤 摆烂 | 用户 7 天未登录 | 躺平、Z Z Z |

> 所有表情都需要**纯色 PNG + 透明背景 SVG** 两套，PNG 用于贴纸卡，SVG 用于动画。

### 3.4 Mascot 出场规则

- 启动页：教练 K 弹出来挥拳套
- 对练房顶栏左侧：表情根据当前情境动态切换
- 评分页：根据综合分换表情
- 空状态：每个 Empty 页面都要有教练 K 占位
- Wrapped 卡：核心吉祥物
- 推送通知：图标用教练 K 表情包

### 3.5 商业延展

> 后期可做实体周边（贴纸、抱枕、搪胶玩具）作为校园推广物料——Z 世代爱收藏。

## 4. 设计 Token

### 4.1 间距（4 倍数）

沿用 v1：`space-1` 到 `space-8`（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64）。

### 4.2 圆角（更圆 · Z 世代审美）

| Token | px | 用途 | 变化 |
|-------|-----|------|------|
| `radius-sm` | 12 | 输入框 / Tag | v1 是 8，**调大** |
| `radius-md` | 20 | 卡片默认 | v1 是 12，**调大** |
| `radius-lg` | 28 | 模态 / 大卡 | v1 是 16，**调大** |
| `radius-xl` | 40 | HUD 主卡 | 新增 |
| `radius-blob` | 64 | Blob 装饰 | 新增 |
| `radius-pill` | 999 | 胶囊按钮（默认） | 沿用 |

> **大圆角是 Z 世代识别度第一来源**。Apple Design Award 近 3 年获奖应用平均圆角 24+。

### 4.3 阴影 / 发光

```css
/* 暗色基础阴影（少用，主要靠发光）*/
--elev-1: 0 2px 8px rgba(0,0,0,0.4);
--elev-2: 0 8px 24px rgba(0,0,0,0.5);

/* 发光（核心强调手段）*/
--glow-purple: 0 0 32px rgba(108,77,255,0.5);   /* 主 CTA */
--glow-green: 0 0 24px rgba(176,255,60,0.4);    /* 封神时刻 */
--glow-pink: 0 0 20px rgba(255,122,182,0.4);    /* 教练表情 */

/* 玻璃描边（Glassmorphism 必备）*/
--glass-border: 1px solid rgba(255,255,255,0.1);
```

### 4.4 动效（弹性 · 弹性 · 弹性）

| Token | 时长 | 曲线 | 用途 |
|-------|------|------|------|
| `motion-fast` | 150ms | ease-out | 状态翻转 |
| `motion-base` | 280ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` | **弹性默认** |
| `motion-bounce` | 500ms | `spring(stiffness: 300, damping: 20)` | 卡片入场 |
| `motion-pop` | 320ms | `spring(stiffness: 500, damping: 15)` | Mascot 弹出 |
| `motion-pulse` | 1500ms 循环 | ease-in-out | 录音指示 |
| `motion-float` | 4000ms 循环 | ease-in-out | Blob 装饰漂浮 |

#### 必备动效场景

- **按钮按下**：scale(0.96) + 100ms 持续 + 触觉反馈
- **卡片入场**：translateY(20) + opacity(0) → spring 入场
- **教练 K 出场**：scale(0.5) + rotate(-10deg) → spring 复位
- **封神瞬间**：粒子烟花（30 个绿点向四周飞散）+ 发光脉冲
- **翻车瞬间**：水平摇晃 3 次（amplitude 8px）

### 4.5 Glassmorphism 标准

```css
.glass-card {
  background: rgba(108, 77, 255, 0.12);
  backdrop-filter: blur(24px);
  -webkit-backdrop-filter: blur(24px);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 20px;
}
```

> 不是无脑加 blur，**只在有色彩背景的层之上用**——纯色背景上加 glass 是浪费。

### 4.6 Blob 背景装饰

每个核心页面都应有 1-2 个**漂浮 Blob**作为背景层（Z=0），增强氛围：

```html
<div class="blob blob-purple"></div>
<div class="blob blob-pink"></div>

<style>
.blob {
  position: absolute;
  width: 320px; height: 320px;
  border-radius: 50% 40% 60% 50% / 50% 60% 40% 50%;
  filter: blur(80px);
  opacity: 0.35;
  animation: float 8s ease-in-out infinite;
}
.blob-purple { background: #6C4DFF; top: -10%; left: -10%; }
.blob-pink   { background: #FF7AB6; bottom: -10%; right: -10%; }
</style>
```

## 5. 栅格与响应式（三端策略）

> v1 锁定三端：**Web 浏览器** + **EXE 桌面**（Tauri 套 Web）+ **微信小程序**（独立 Taro 项目）。前两端共享设计稿与组件，小程序端作差异化适配。

### 5.1 栅格基础

| 设备 | 列数 | 列间距 | 边距 | 内容最大宽 |
|------|------|--------|------|-----------|
| 手机（小程序）| 4 | 16 | 16 | 100% |
| 平板（Web）| 8 | 24 | 24 | 100% |
| 桌面（Web/EXE）| 12 | 32 | 64 | 1280 |

### 5.2 三端能力与设计差异

| 能力 | Web 浏览器 | EXE 桌面 | 微信小程序 |
|------|:--------:|:--------:|:----------:|
| 沙盘对练 | ✅ 全功能 | ✅ 全功能 | ✅ v1 仅文字 |
| 实战副驾 | ✅ | ✅✅ **核心**（后台麦克风）| ❌ 不做 v1 |
| 复盘师 | ✅ 三栏 | ✅ 三栏 | ✅ 单列竖屏适配 |
| Wrapped 卡分享 | ✅ 保存图片 | ✅ 保存图片 | ✅✅ **核心**（一键转发微信）|
| 教练 K Mascot | ✅ Rive 动画 | ✅ Rive 动画 | ⚠️ **Lottie 兜底** |
| 微信登录 | — | — | ✅ wx.login |
| 全局快捷键 | ❌ | ✅ 老板键 | ❌ |
| Glassmorphism | ✅ | ✅ | ⚠️ 简化（小程序 backdrop-filter 兼容差）|

### 5.3 微信小程序专属设计约束

| 项 | 限制 | 应对设计策略 |
|----|------|--------------|
| 主包大小 ≤ 1.5MB | 严格 | Mascot 表情 PNG 放分包；字体走系统默认（不嵌入）|
| 不支持 Rive | 必须 | 8 表情用 Lottie .json（< 50KB/个）兜底；关键动画用 PNG 序列帧 |
| 不支持 backdrop-filter | 部分支持 | Glass 卡降级为半透明 + 边框描边（视觉差异 < 10%）|
| 不支持 framer-motion | 是 | 用 Taro `Animation API` + 自定义曲线 |
| 不支持 IndexedDB | 是 | 用 wx.setStorage（每 key ≤ 1MB，总 5MB）|
| 必须遵守内容审核 | 是 | 用户输入提交前先调微信内容安全 + 后端二次审核 |
| 域名白名单 | 严格 | 所有 API 域名提前在 wxapp 后台配置 |
| 分享卡片要走规定 path | 是 | 统一用 `/pages/share/[type]?id=...` |

### 5.4 跨端组件适配策略

> 同一组件名在三端的实现差异（详见 §6 组件库）：

| 组件 | Web/EXE 实现 | 小程序实现 |
|------|--------------|-----------|
| MascotReaction | Rive + framer-motion 弹簧 | Lottie + Taro Animation |
| GlassCard | backdrop-filter blur(24px) | rgba 半透明 + 1px 描边 |
| WrappedCard | Canvas 渲染 + Save File API | wx.canvasToTempFilePath + wx.saveImageToPhotosAlbum |
| StickerBadge | CSS transform rotate | Taro view + transform 一致 |
| BlobBackground | filter blur 大 div | 静态 PNG 渐变图（性能考量）|
| HUDWidget | 全屏 + 麦克风权限 | **不实现**（副驾不做小程序）|
