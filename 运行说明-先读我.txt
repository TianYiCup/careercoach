CareerCoach AI · 一键启动（Windows）
=====================================

第一步：配置后端密钥
   复制  apps\api\.env.example  为  apps\api\.env，填入你自己的密钥：
   DEEPSEEK_API_KEY / ALIYUN_ACCESS_KEY_ID / ALIYUN_ACCESS_KEY_SECRET / ALIYUN_ASR_APP_KEY
   （不填则沙盘出假数据、副驾语音不可用、审核走本地词典；保存为 UTF-8 无 BOM）

第二步：双击启动（二选一）
   ● 启动演示.bat     桌面版（推荐）：起后端 → 打开桌面应用
                       注：桌面应用 app.exe 需已打包。从源码检出可先
                       cd apps\web && pnpm tauri build，或直接用网页版。
   ● 启动网页版.bat   网页版：起后端 → pnpm dev → http://localhost:5173
                       额外需 Node.js + pnpm（脚本尝试自动装，较重）。

必须联网（后端连 DeepSeek / 阿里云）；副驾还需麦克风权限。

脚本做了什么：装 uv → uv sync 装后端依赖 → 起 uvicorn(127.0.0.1:8000)
→ 桌面版打开 app.exe / 网页版 pnpm dev。

手动启动后端：
   cd apps\api && uv sync && uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
